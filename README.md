# Nexora

Nexora is a marketplace web application focused on product comparison,
variants, offers and prices from different stores.

## Technologies

- PHP 8.5
- Laravel 13
- PostgreSQL
- JavaScript
- Blade
- Tailwind CSS
- Vite
- Docker
- Docker Compose

## Current Features

- Product detail page
- Product image gallery
- Product categories
- Product attributes and variants
- Variant selection
- Store offers
- Price comparison
- Stock information
